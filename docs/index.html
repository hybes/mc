First time?

  1. Install Prism Launcher.
  2. In Prism, open Accounts and sign in with the Microsoft account that owns Minecraft Java.
  3. Come back here and click Install.

If Install does nothing, use “Download zip instead”, then in Prism choose Add Instance, Import, and pick the zip.
